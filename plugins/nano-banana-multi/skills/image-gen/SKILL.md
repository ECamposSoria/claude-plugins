# Nano Banana Multi: image, AI video and 3D generation

Two scripts, both run with `uv run`:

- `scripts/image.py`: images through Gemini (`flash`, `pro`), gpt-image-2 via the Codex CLI (`codex`) and the
  Antigravity CLI image subagent (`agy`). Images only.
- `scripts/fal.py`: any fal.ai endpoint (images, video, 3D, masks, upscalers, interpolation) with one key,
  behind a **spend guard**.

`${SKILL_DIR}` below is the directory holding this file.

## Scope: generation stops here

| After generating you need to… | Go to |
|---|---|
| Cut, assemble, caption, add voiceover/music, check a clip for pops, deliver a video | `video-studio:video-studio` (`/video`) |
| Put an image or a 3D model on a web page | `website-builder:website-builder` |

## Prerequisites (each only for its backend)

- `GEMINI_API_KEY` for `flash` / `pro`.
- Codex CLI signed in for `codex`: uses the ChatGPT plan, no `OPENAI_API_KEY`.
- `agy` (Antigravity CLI 1.4+) signed in for `agy`: uses the Google AI Pro subscription.
- `FAL_KEY` for `fal.py`: environment, else `~/.secrets/fal.env` (`FAL_KEY=...`, mode 600). Never put it in a
  repo, a prompt or a log.

## Pick the backend

| You need… | Use | Cost |
|---|---|---|
| A photo edit or composite from several references | `image.py --model agy` first | free (subscription) |
| Same, when agy fails or needs a second opinion | `image.py --model codex` | ChatGPT plan |
| Fast or batch images from text | `image.py --model flash`, or `pro` for 2K/4K | Gemini API |
| An edit that must keep everything else intact, or both CLIs failed | fal `openai/gpt-image-2.5/flare/edit` | $0.039 |
| A realistic video clip | fal `fal-ai/kling-video/v3/pro/image-to-video` | $0.112/s |
| A 3D model of a real product | fal `fal-ai/hunyuan-3d/v3.1/pro/image-to-3d` | $0.375, up to $0.825 with add-ons |
| Removing an object from a photo | fal `fal-ai/finegrain-eraser/mask` | $0.045 |
| A fal model refused a legitimate brief | Venice, see `references/fal-endpoints.md` | credits |

Full endpoint tables, 3D options, prices and traps: **`references/fal-endpoints.md`**. Read it before any
video or 3D run. Prompt structure, the real-product fidelity anchor and motion prompts:
**`references/prompt-craft.md`**. Read it before writing any prompt that matters.

## image.py

```bash
uv run "${SKILL_DIR}/scripts/image.py" --model agy --aspect landscape \
  --reference /path/location.jpg --reference /path/product.jpg \
  --prompt "..." --output /path/out.png
```

| Flag | Values |
|---|---|
| `--model` | `flash` (default, 1024 px), `pro` (up to 4K), `codex` (gpt-image-2; `gpt` is a deprecated alias), `agy` |
| `--aspect` | `square` (default), `landscape`, `portrait` |
| `--reference` | repeatable; every backend accepts several |
| `--size` | `1K`/`2K`/`4K`: exact for `pro`, a loose hint for `codex`, ignored by `flash` and `agy` |
| `--quality` | `auto`/`low`/`medium`/`high`, `codex` only |

Backend traits:

- **agy**: best free multi-reference edit (kept wall lettering near pixel-exact in a 3-reference test,
  1.5–2.5 min). Output is fixed at **1376×768** for 16:9 whatever `--size` says; for 1080p keyframes upscale
  with `fal-ai/seedvr/upscale/image` (`upscale_factor=2`, ~$0.003). It strips `GEMINI_API_KEY` and
  `GOOGLE_API_KEY` so the subscription is billed, defaults its orchestrator to `gemini-3.8-flash-high`
  (`AGY_IMAGE_MODEL` overrides) because Gemini 4 Argon's weekly quota runs out, and needs references as
  readable paths. Its self-reported model name is unreliable.
- **codex**: runs `codex exec` with each reference attached; the PNG lands in
  `~/.codex/generated_images/` and is copied to `--output`. 1–3 min; occasionally times out on 3+
  references. Returns non-standard sizes (1254×1254, 1448×1086, 1672×941).

## fal.py

1. **Find the endpoint.** The catalog changes weekly; never trust a remembered id:
   `uv run "${SKILL_DIR}/scripts/fal.py" search "image to 3d" --category image-to-3d`
2. **Read its inputs.** Names differ per model (`image_url`, `image_urls`, `start_image_url`,
   `input_image_url`): `uv run "${SKILL_DIR}/scripts/fal.py" schema <endpoint>`
3. **Find the real price** on `https://fal.ai/models/<endpoint>` or in `references/fal-endpoints.md`.
   `fal.py price` is only a hint.
4. **Dry-run, then run.** Values go in with `--arg key=value` (JSON-parsed, so `duration=10` is a number),
   local files with `--file key=path` (uploaded only after the guard passes); a `[]` suffix appends to a list.

```bash
uv run "${SKILL_DIR}/scripts/fal.py" run fal-ai/kling-video/v3/pro/image-to-video \
  --file start_image_url=/path/start.png --file end_image_url=/path/end.png \
  --arg prompt="..." --arg duration=5 --dry-run --out /path/clip.mp4
```

Nested inputs (e.g. Kling O3 `elements[].frontal_image_url`) can't use `--file`: run `fal.py upload a.png`
to get URLs, then pass them inside `--arg elements='[...]'`. `--out` is a file when there is one output,
else a directory; the raw result is saved beside it as `fal-<request_id>.json`. Run video and 3D jobs with
`run_in_background`: they take minutes.

5. **Recover instead of paying twice.** `request_id` is printed before waiting. If the process dies:
   `uv run "${SKILL_DIR}/scripts/fal.py" result <endpoint> <request_id> --out /path/clip.mp4`

### Spend guard

`run` estimates the cost before uploading anything and exits with code 3 when the spend is not allowed.
**Every paid run passes `--max-usd`** with the full price for this request, worked out from the model page or
`references/fal-endpoints.md` (duration × rate, image count, resolution, audio, add-ons). The pricing API is
only a floor: resolution, quality, audio and their schema defaults have each raised a real price above it.

| Guard says | Do |
|---|---|
| read the price and rerun with `--max-usd` | Work out the full price, rerun with `--max-usd <it>` |
| above the approval threshold (`FAL_APPROVE_USD`, default $0.50) | **Ask the user**, quoting the price. Rerun with `--approved` only after they say yes. |
| over the monthly cap (`FAL_MONTHLY_CAP_USD`, unset = no cap) | Report month-to-date spend; `--over-cap` only if the user raises or waives the cap. Runs from the last hour count twice (usage + their reservation) so parallel jobs can't slip past the cap; if that alone blocks a run, show `fal.py spend` and ask. |

The endpoint's schema defaults are merged in before estimating (an omitted `duration` uses its default), and
the higher of the API floor and `--max-usd` is what gets approved. Never pass `--approved` or `--over-cap` on
your own judgement. `--dry-run` shows the arguments, the estimate
and the decision without uploading or submitting. `fal.py spend [--since YYYY-MM-DD]` prints real spend
per endpoint from fal's usage API (default: this month). Each submitted run is logged to
`~/.cache/nano-banana-multi/fal-ledger.jsonl`.

## Video clips: what holds up

- One clip carries **one** camera move and **one** action. Big state changes (an inflatable going from flat to
  full, people entering and leaving) make Kling pop for a single frame; use shorter shots or a start frame only.
- Pass a start **and** an end frame when both matter; it costs nothing extra per second.
- Kling 3.0 Pro generates audio unless told not to ($0.168/s instead of $0.112/s): `--arg generate_audio=false`
  when the sound will be replaced. Kling 4.0's `resolution` defaults to `1080p`.
- Kling rewrites background lettering and clothing text in motion. Plan for it in the frame, not in post.
- Draft at 720p, finals at 1080p, at most three takes per shot.
- **Every generated clip goes through `video-studio`'s `qa_render.py --mode clip` before it is used.** One-frame
  pops are invisible at playback speed and obvious to a client on a phone.
