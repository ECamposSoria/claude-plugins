# framer

Connect Claude Code directly to your **Framer** projects — edit the canvas, manage CMS
collections, create code components, manage styles/localization, and publish — via
Framer's official [`@framer/agent`](https://www.framer.com/agents/external/) integration.

## Important: Framer has no MCP server

Unlike the other plugins in this marketplace (stitch, scraper, google-docs…), Framer's
official answer to "is there a Framer MCP?" is **no**. The integration is **Skills + a
local CLI**, not the Model Context Protocol. So this plugin ships a **skill**, not a
`.mcp.json`. There is nothing to add via `claude mcp add` or `plugin marketplace add` for
Framer beyond installing this plugin.

## Requirements

- **Node ≥ 22** (the `@framer/agent` package `engines` floor; Framer *recommends* ≥ 24).
  You already use nvm — `nvm install 24 && nvm use 24` if you want the recommended line.
- Network access for `npx` to fetch `@framer/agent` and reach Framer's servers.
- A Framer account + the project(s) you want to work on.

## Install

```bash
claude plugin marketplace update eze-claude-plugins
claude plugin install framer@eze-claude-plugins
```

Then restart Claude Code so the skill is picked up.

## First run

The skill's mandatory first step installs the full official skill suite globally
(`~/.claude/skills` + `~/.agents/skills`):

```bash
npx @framer/agent@latest setup
```

Then connect to a project (e.g. the Abundant-Page project) and grant access in the
browser when prompted:

```bash
npx @framer/agent@latest session new "https://framer.com/projects/Abundant-Page--2sbbDWaTFerJWiiuOabO-5HnKo"
```

After that, just ask Claude to build/edit/import — it works directly on the Framer canvas
(on an auto-created branch; nothing goes live until you publish).

## What this plugin bundles vs. what `setup` adds

- **Bundled here:** the `framer` entry skill (session management + CLI usage).
- **Added by `setup` at runtime:** `framer-code-components` and the per-project
  `framer-project-<id>` skill (dynamically generated by `session new` — it is *not*
  bundled because it is project-specific and templated at connect time).

## Notes / caveats

- The bundled skill is Framer's content, lightly adapted (templated `allowed-tools`
  file paths removed so it works standalone). The CLI itself is always pulled fresh via
  `npx @framer/agent@latest`, so tool behavior stays current; only the bundled
  instructions could drift between Framer releases. Re-running `setup` refreshes the
  global copies.
- This is **not** a one-click "import my existing live website." The agent *builds* in
  your Framer project; recreating an existing site is work done through this connection
  from your source (repo/URL/screenshots).
